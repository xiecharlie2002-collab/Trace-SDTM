# TraceSDTM Studio 0.5 用户手册

## 1. 定位与边界

TraceSDTM Studio 是单用户、本地运行的 SDTM 映射工作台。浏览器只是操作界面，数据和产物保存在本机。系统目前只生成 DM、AE、VS，不包含电子签名、多人权限、数据库、Define-XML 或法规申报级系统认证。

工作台的职责分工是：模型提出候选，审核者作出判断，注册表限制合法函数与参数，R程序确定性生成数据，本地规则与 Pinnacle 21 分别检查，所有关键步骤保留校验值和审计事件。

## 2. 安装与启动

要求 R 4.5.0 或更高版本。进入项目目录后执行：

```powershell
Rscript -e "install.packages('renv', repos='https://cloud.r-project.org')"
Rscript -e "renv::restore()"
.\scripts\start_trace_sdtm_studio.ps1
```

启动器在3838至3848中寻找可用端口，只绑定 `127.0.0.1`。如需显式端口或不自动打开浏览器：

```powershell
.\scripts\start_trace_sdtm_studio.ps1 -Port 3839 -NoBrowser
```

检查环境：

```powershell
Rscript scripts/trace_sdtm.R studio-doctor
```

项目默认位于 `workspace/projects`。要放到其他磁盘，可在启动前设置：

```powershell
$env:TRACE_SDTM_STUDIO_HOME = 'D:\TraceSDTM-Projects'
```

## 3. 从项目到报告的操作顺序

### 项目

填写项目编号、项目名称、模板和研究编号。项目编号只使用小写字母、数字和连字符。基础、中等、高级模板分别对应18、49、57个固定原子任务。

创建时会冻结任务、元数据、函数注册表、术语、单位和初始政策，但不会复制金标准。项目只能归档，网页不提供删除。

### 数据源

为每个非派生来源槽位上传一个CSV。文件必须是UTF-8或UTF-8 BOM，默认上限100 MB。系统拒绝空字段名、重复字段名、无法解析的文件和越界路径。

字段绑定建议只根据规范化名称、标签、类型和编辑距离产生，不调用模型。逐项确认上传字段与模板逻辑字段后，系统检查键缺失与模板规定的唯一性，并写入规范化暂存CSV。原文件保持不变。

### 项目政策

在受控选项内设置研究编号、受试者标识符、中心编号、日期时间格式、参考日期选择、AE与VS序号排序、访视编号、基线规则、术语映射和单位目标。单位乘数与偏移量来自冻结的版本化换算表，不能在网页输入。

修改上传文件、字段绑定或政策后，当前运行会标记为过期。旧运行仍保留且只读。

### 数据画像

点击“创建运行并开始画像”。系统冻结当前规范化数据和配置，创建新的 `run_id`。字段画像显示类型、缺失比例、唯一值数量、格式候选、来源关系和本地示例；本地示例默认不会进入模型请求。

### 映射推荐

模型配置可以来自当前终端的环境变量，也可临时输入网页。网页密钥只存在于当前会话内存，并通过环境变量传给一个后台子进程。

建议先点击“生成完整请求预览及校验值”。默认请求只包含元数据。勾选示例授权时，还必须选择具体字段；标识符、键和中心字段无论如何都不会发送示例值。

一键推荐按顺序执行：目标变量识别、转换函数选择、已知参数自动注入、有限未知参数补全和候选计划组装。也可分阶段运行以便定位错误。一个任务失败不会使同组无关任务失效，依赖失败只阻止下游任务。

### 人工审核

每个原子任务选择接受、修改、拒绝或信息不足。接受时选择候选序号；修改时只能选择注册表允许的函数、来源编号、目标变量和结构化参数。必需任务不能拒绝，信息不足未解决时不能批准。

审核者标识必须填写，不能使用默认演示名称。网页审核和Excel导入使用同一严格校验函数。批准后同时保存0.5审核状态、Excel快照和供构建读取的0.4兼容YAML规格。

### 构建

点击生成后，系统只读取批准规格，不调用模型。输出包括DM、AE、VS的CSV和XPT、字段级追溯、数据集清单、运行日志和文件校验值。

### 验证

本地检查不依赖 Pinnacle 21。若本机环境检查通过，可自动调用Pinnacle 21 Community；否则可在图形界面中验证XPT，再上传生成的Excel报告。

缺少Define-XML、TS和未覆盖域等问题会保留并归为最小项目范围，不能据此声称完整申报包通过。重点是DM、AE、VS内部没有未解释的高严重程度缺陷。

### 追溯与报告

追溯表可按域、变量、任务或函数筛选。离线HTML报告不依赖网络。证据包包含批准规格、CSV、XPT、追溯、验证、报告、配置快照和审计事件，但不包含原始上传文件或字段示例值。

## 4. 后台任务与恢复

工作台同时只运行一个后台任务，每500毫秒刷新脱敏日志。可以取消任务；取消状态写入运行清单。应用异常退出后，再次启动会把已经不存在进程对应的 `running` 状态标记为 `interrupted`，不会自动重放。

项目锁防止网页与命令行同时写入同一项目。如果看到项目被占用，应先确认另一个任务是否仍在运行，不要手工并发执行写操作。

## 5. 对应命令行

工作台运行可使用相同执行核心：

```powershell
Rscript scripts/trace_sdtm.R profile --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R recommend --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R build --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R validate-local --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R validate-p21 --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R report --project <项目编号> --run <运行编号>
Rscript scripts/trace_sdtm.R export-evidence --project <项目编号> --run <运行编号>
```

普通工作台项目不包含金标准，因此禁止 `--seed`、`review-gold` 和准确率评价命令。

## 6. 常见问题

“字段绑定不能通过”：检查必需字段是否全部绑定、同一上传字段是否被重复绑定，以及键是否缺失；一记录粒度的模板还要求键唯一。

“当前运行已过期”：上传、绑定或政策在运行创建后发生变化。返回数据画像页创建新运行；旧运行不应覆盖。

“模型配置缺失”：在当前终端设置三个 `TRACE_SDTM_*` 环境变量，或在映射推荐页临时输入。不要把密钥写入项目配置。

“Pinnacle 21自动调用失败”：先在验证页运行环境检查。确认本地 `config/p21.local.yml` 中的安装路径与版本；也可改用Excel报告导入。

“端口已占用”：不指定端口让启动器自动选择，或换用3838至3848中的其他端口。工作台不会改为监听外部网卡。

## 7. 备份建议

停止后台任务后备份整个工作台项目目录。每个运行已经包含输入校验值、配置快照和产物；证据包适合审阅和展示，但默认不包含原始上传文件，因此不能替代项目目录备份。
