# TraceSDTM Studio 0.6 五分钟演示

## 0:00—0:35：启动与项目隔离

```powershell
.\scripts\start_trace_sdtm_studio.ps1
```

展示地址为 `127.0.0.1`，然后在“项目”页切换两个本地项目。说明上传、配置和每个 `run_id` 相互隔离，网页只能归档，不能删除历史。

## 0:35—1:20：通用数据与画像

在“项目与数据”页一次上传多个 CSV，展示按文件名生成的数据集编号、实际字段画像、候选键、记录粒度和不可直接执行的关系候选。

## 1:20—2:05：任务发现与映射生成

在“任务确认”页由人工智能生成原子任务，展示程序错误、人工编辑和冻结。随后在“映射生成”页执行目标变量、函数和参数阶段；已知参数由程序注入，有限选项才交给模型，自由参数由人工填写。

## 2:05—2:55：独立审查与规格锁定

在“审查批准”页执行独立人工智能审查，展示错误阻止批准、警告必须填写说明。接受一项并结构化修改一项，重新审查后最终批准。Excel 只作为只读审计导出。

## 2:55—3:45：确定性构建与追溯

点击“生成DM、AE、VS”，依次展示：

- 两个暴露文件取得最早给药日期时间；
- AE 与 SAE 受控一对一连接；
- 不完整日期保持最大已知精度且不填补；
- 英寸、磅、华氏度通过版本化换算表转换；
- VS 横向转纵向并派生 VSBLFL；
- `field_lineage.csv` 记录每一步、连接规则、sdtm.oak 版本、审核者和记录数。

## 3:45—4:30：双层验证

- 本地检查 0 个问题；
- Pinnacle 21 的 DM、AE、VS 域内问题为 0；
- 缺少 Define-XML 和 TS 的 Reject 原样保留并归为最小范围。

## 4:30—5:00：报告、证据包和结论

打开离线报告并下载证据包，说明包内有批准规格、CSV、XPT、追溯、验证、报告、配置快照和审计事件，但没有原始上传文件、字段示例值或密钥。

“项目体现的不是提示词技巧，而是可治理的自动化设计：模型推荐、专家判断、注册表约束、确定性执行、独立验证和全程追溯。高级场景专门证明它能处理真实项目中较难的连接、日期精度和单位问题。”

## 简历表述示例

基于 Shiny、R、sdtm.oak 与 Pinnacle 21 Community 构建单用户本地 SDTM 映射工作台，覆盖 DM、AE、VS；实现通用多 CSV 上传、自动画像、人工智能任务发现、多阶段映射、程序参数注入、独立人工智能审查、结构化人工批准、规格驱动构建、字段级追溯和证据包导出，并以运行快照、项目锁和会话内密钥控制保证可复现性与隐私边界。
